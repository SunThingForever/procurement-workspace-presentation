# Procurement Workspace

## Short description

*Idea from ChatGPT and Deepseek, refine by Claude*

Procurement Workspace is an AI agent that reads supplier quotations, cites source documents, and compares eligible options by total cost. It flags missing information, reduces manual data entry, and supports human approval with an audit trail.

## Long description

*Idea from ChatGPT and Deepseek, refine by Claude*

The cheapest unit price can become the most expensive order once tooling, delivery, taxes, and minimum quantities are counted. Procurement Workspace’s AI agent uses Vultr Serverless Inference to extract key terms from supplier quotations, linking each to its source document. Python checks eligibility and calculates comparable costs for the required quantity. The agent flags missing information and explains trade-offs using recorded supplier performance, so a human reviewer can approve, reject, or request clarification. Manual data entry shrinks, comparison accelerates, approvals gain clarity, and every decision leaves a traceable record, while delivery and quality outcomes inform future evaluations.
